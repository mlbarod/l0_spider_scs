## 1. 访问服务与功能状态

在 SPIDER 主页选择功能卡片。只有右上角标记为 `运行中` 的卡片是当前可正常使用的功能。

| 状态 | 功能 |
|---|---|
| 运行中 | 设备异常检测、同条件异常检测、用户手册 |
| 计划中 | 公共区域异常检测、公共区域同条件异常检测、FDC Hard Limit 推荐、MY EQP 注册、Defect SPIDER、L1 SPIDER、L3 SPIDER |

主页下方的 `产线异常检测仪表板` 当前可用。选择 `计划中` 卡片时，将显示功能准备提示，而不是进入功能页面。

## 2. Dashboard 使用方法

Dashboard 用于查看各产线的异常情况和近期趋势。

1. 选择查询开始日期和结束日期。
2. 选择需要的产线。未选择时将查询全部产线。
3. 选择 `查询`。
4. 在 KPI 卡片中查看监控传感器总数、异常总数、各 Grade 数量及较前一日变化。
5. 查看 `各产线异常情况`、`各产线每日异常趋势` 和 `产线详情`。

`重置`会将查询条件恢复为默认值。`重试`会使用当前条件重新加载服务器数据。选择详情表的列标题可以进行排序。

如果主页顶部的 `算法最后运行时间` 显示为 `无法确认`，请联系运维人员确认数据状态，不要反复刷新。

## 3. 设备异常检测

### 3.1 筛选顺序

请从左到右依次选择筛选条件。

1. `Line Name`
2. `SDWT`
3. `Sensor Grade`
4. `PRC_Group`
5. `eqp_ch`
6. `sensor`
7. `ch_step`

前一项选择会改变后一项的候选值。如果找不到所需值，请检查前置筛选条件、数据日期或 Sensor 排除设置。`重试`会重新加载当前条件的数据。

### 3.2 查看图表

完成筛选后，`散点图`区域将显示各 EQP 的图表。

- `汇总 ch_step`：在同一区域查看同一 EQP 的多个 `ch_step`。
- `显示全部 ch_step`：从汇总视图恢复为单个图表。
- `同条件图表`：在单独窗口中查看所选 EQP 的同条件数据。
- `显示三日同条件图表`：在汇总视图右侧显示最近 72 小时的同条件图表。
- `变更记录`：查看 EQP 作业记录和可用 LINK。

无图表数据并不一定表示查询失败。请先确认是否存在与所选条件匹配的源数据。

### 3.3 SKIP 操作

只有在 DB capability 已启用且用户信息准备完成后，才能使用 `SKIP`、`EQP ALL SKIP` 和 `解除 SKIP`。

- `SKIP`：排除当前异常记录。
- `EQP ALL SKIP`：批量排除所选 EQP 和 Sensor 的多个 `ch_step`。
- `SKIP LIST`：按照与普通设备视图相同的 `PRC_Group` 筛选顺序查看该产线已排除的记录。
- `解除 SKIP`：恢复已排除的记录。

执行操作前，请再次确认目标 EQP、Sensor 和操作范围。请勿在生产 DB 中创建测试用 SKIP 记录。

## 4. 同条件异常检测

1. 在主页选择 `同条件异常检测`。
2. 选择 `Line Name`。
3. 选择 `SDWT`。
4. 选择 `STEP`。
5. 选择 `Sensor` 和 `ch_step`。
6. 在结果区域查看同条件图表。

`ch_step` 的 `ALL` 是将当前筛选条件下多个结果汇总显示的界面选项，与旧版 MY EQP 邮件链接中的 `step=ALL` 含义不同。

结果较多时可使用分页按钮。`重试`会重新确认最新路径和当前筛选条件。

## 5. 计划功能

以下功能显示在主页上，但当前不可使用。

- 公共区域异常检测
- 公共区域同条件异常检测
- FDC Hard Limit 推荐
- MY EQP 注册
- Defect SPIDER、L1 SPIDER、L3 SPIDER

即使知道 MY EQP 注册 route 或旧页面地址，也不表示当前支持注册、查询或邮件发送。Mailing Report 的实际生成和定时发送也不在当前服务范围内。

## 6. 故障排查与注意事项

| 页面消息或现象 | 检查内容 |
|---|---|
| `没有与所选筛选条件匹配的数据。` | 检查前置筛选条件和数据日期。 |
| 无法加载数据 | 稍后选择 `重试`。如果问题持续，请向运维人员提供 URL、发生时间和所选条件。 |
| DB capability 未启用 | 查询可能仍可使用，但无法执行 SKIP 和记录操作。 |
| 最后运行时间显示 `无法确认` | 请运维人员检查 Dashboard 最新数据或连接状态。 |
| 计划功能提示 | 这不是错误，表示该功能尚未提供。 |

注意事项：

- 请勿修改浏览器地址中的 query 参数来绕过权限或数据限制。
- 请勿向组织外部共享页面中显示的内部路径或用户信息。
- 请勿为了重现错误而直接修改生产数据、DB 或 Sensor 设置。
- 报告问题时，请勿包含真实密码、token 或 credential。
