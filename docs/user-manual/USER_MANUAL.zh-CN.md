## 1. 开始使用

### 1.1 首次访问

首次访问时会显示 `用户登记` 页面。

1. 输入本人的 `knox_id`。不要输入邮箱地址（不含 @）。
2. 点击 `登记并继续`。

登记一次后，从同一台 PC 再次访问时会自动识别。

### 1.2 切换语言

在主页右上角点击 `한국어` / `English` / `中文`。所选语言在下次访问时仍会保留。

### 1.3 主页

| 区域 | 内容 |
|---|---|
| `算法最后运行时间` | 异常检测数据最后更新的时间 |
| 功能卡片 | 设备级 SPEC 内异常检测、同条件异常检测、历史记录看板、MY EQP 注册、用户手册 |
| 关联功能卡片 | Defect SPIDER |
| `产线异常检测仪表板` | 主页下方的各产线异常情况 |

点击卡片即可进入对应功能。在各功能页面点击 `SPIDER 主页` 或 `返回首页` 可回到主页。

## 2. 通用操作

筛选条件请**从左（上）到右依次**选择。更改前面的条件后，后面的选择会被清空。

- **选择/取消**：点击项目即可选择，再次点击已选项目即可取消。
- **`ALL`**：一次查询当前列表中显示的全部项目。
- **搜索**：在筛选卡片的 `搜索…` 框中输入。
  - 用搜索框左侧的按钮选择 `包含`（只显示含有输入文字的项目）或 `排除`（只显示不含输入文字的项目）。
  - 不区分大小写。
  - 搜索时选择 `ALL`，只查询**搜索结果中显示的项目**。
- **筛选区域大小**：拖动筛选区域下方的手柄调整高度。双击手柄可恢复默认大小。
- **`重试`**：加载失败时，以相同条件重新加载。
- 点击右下角的箭头按钮可返回顶部。

## 3. 产线异常检测仪表板

在主页下方（顶部 `仪表板` 菜单）查看各产线的异常情况。

1. 在 `选择产线` 中勾选要查看的产线。不勾选时查询 `全部产线`。
2. 点击 `查询`。
3. 查看结果。

| 区域 | 查看方法 |
|---|---|
| KPI 卡片 | 监控传感器总数、异常总数、各 Grade 数量、`较前一日` 增减（▲ 增加 / ▼ 减少） |
| `各产线异常情况` | 各产线异常数量柱状图。**点击柱子只查询该产线。** |
| `各产线每日异常趋势` | 用期间按钮（10/30/90/180 天）切换范围。点击图例可隐藏或重新显示该产线。 |
| `产线详情` | 点击列标题排序。点击 `详情` 进入设备级 SPEC 内异常检测页面。 |

点击 `重置` 会恢复为全部产线、10 天趋势，并重新显示已隐藏的产线。

## 4. 设备级 SPEC 内异常检测

查看各设备的异常检测图表，必要时进行 SKIP 处理。

### 4.1 查询

1. 选择 `Line Name`。
2. 选择 `SDWT`。
   - `MY EQP`：只查看我注册的 MY EQP 设备。仅在有注册设备时显示。
   - `SKIP LIST`：只查看已 SKIP 的图表。
3. 选择 `传感器等级`。可多选。
   - 选择等级后，其余条件（`PRC_Group`、`eqp_ch`、`sensor`、`ch_step`）自动设为 `ALL`，状态设为 `CRITICAL`，并立即显示图表。
4. 如需缩小范围，按 `PRC_Group` → `eqp_ch` → `sensor` → `ch_step` 的顺序选择。

### 4.2 查看图表

| 按钮 | 功能 |
|---|---|
| `CRITICAL` / `WARNING` | 只显示该状态的异常。再次点击显示全部。 |
| 页码 | 每页显示 20 个图表。 |
| `汇总 ch_step` / `显示全部 ch_step` | 将同一 EQP 的图表汇总查看，或逐个展开查看。（默认：汇总） |
| `显示三日同条件图表` | 在汇总状态下，在右侧同时显示最近 3 天（72 小时）的同条件图表。（默认：开启） |
| `同条件图表` | 打开与同一数据中其他设备比较的窗口。当前 EQP 为红色。开启 `绘制参考线` 后点击两次可标记参考区间。 |
| `变更记录` | 以表格查看设备作业记录。有 `LINK` 时可打开相关页面。 |
| `保存记录` | 将图表连同图片保存到 [历史记录看板](#7-历史记录看板)。 |

图表操作：**拖动放大**，**双击恢复原始范围**。红点为异常数据，灰点为历史数据，绿色虚线为变更点。

### 4.3 SKIP

| 按钮 | 功能 |
|---|---|
| `SKIP` | 将当前图表从异常检测中排除。输入一行原因（可选）后点击 `确定`。 |
| `EQP ALL SKIP` | 一次排除该 EQP·sensor 的所有 ch_step。 |
| `解除 SKIP` | 将已排除的图表恢复为异常检测对象。 |

已 SKIP 的图表可在 `SDWT` → `SKIP LIST` 中查看并解除。操作前请再次确认目标 EQP 和 sensor。

## 5. 同条件异常检测

查看比较相同条件下设备间信号分布的图表。

1. 选择 `Line Name`。（自动选择第一条产线）
2. 选择 `SDWT`。（自动选择第一个 SDWT）
3. 选择 `STEP`。`ALL` 表示该 SDWT 的全部 STEP。
4. 选择 `Sensor`。
5. 选择 `ch_step` 后显示图表。Sensor 为 `ALL` 时，ch_step 只能选择 `ALL`。

结果按 step_seq 分组显示在 `同条件异常检测图表` 中。

- 每页显示 18 个，可用下方页码翻页。
- 点击各图表的 `保存记录` 可保存到 [历史记录看板](#7-历史记录看板)。

## 6. Defect SPIDER 使用方法

以图表查看基于 Defect 信号的异常检测结果。数据以**当天最新的异常检测列表**为准。

此页面部分文字以韩文显示，下文附有中文说明。

### 6.1 查询

1. 选择 `步骤类型`。
   - `管理步骤`（默认）：管理步骤的异常检测结果
   - `DEPO后步骤`：DEPO 之后步骤的异常检测结果
2. 选择 `Line Name`。（自动选择第一条产线）
3. 选择 `SDWT`。（自动选择第一个 SDWT）
4. 选择 `PRC Group`。默认值 `ALL` 显示所有 PRC Group 的图表。

切换 `步骤类型` 后，PRC Group 会恢复为 `ALL`，并用所选步骤的数据重新绘制图表。

### 6.2 查看图表

图表按 PRC Group 分组，每个 eqp_ch 显示一个图表。图表标题为 `eqp_ch / main_seq / met_seq` 信息。

| 标记 | 含义 |
|---|---|
| 小而浅的点 | ALL 数据（按 STEP 着色） |
| 大而深的点 | 异常检测 RAW 数据（红色：NG，青色：其他） |
| 绿色虚线 | 变更点（PM 记录） |
| 右侧图例 | STEP 颜色和数量、eqp_ch 列表。**点击 eqp_ch** 可隐藏或重新显示该设备的点。 |

图表操作：

- **拖动**：放大所选区域
- **反方向拖动**：恢复初始范围
- **双击** 或 `범위 초기화`（重置范围）：查看全部范围

### 6.3 查看详情

- `이상감지 Wafer List 보기`（查看异常 Wafer 列表）：以表格打开异常 Wafer 列表。拖动选择单元格或点击列标题选择后，点击 `복사`（复制）或按 Ctrl+C，即可粘贴到 Excel。
- `PM이력 보기`（查看 PM 记录）：以表格打开该设备的 PM 记录。

## 7. 历史记录看板

集中查看在各页面用 `保存记录` 保存的图表。也可以在保存后弹出的窗口中点击 `前往历史记录看板`。

1. 按需输入条件：`Line Name`、`SDWT`、`保存人`、`保存开始日期`、`保存结束日期`。
   - Line Name、SDWT、保存人须输入**完全一致**的值才能查到。
2. 点击 `查询`（或按 Enter）。`重置` 清空所有条件。
3. 在列表中点击 `记录详情`，可查看保存时的图表图片和信息。

- 按保存时间从新到旧排列，每页 20 条。用 `上一页` / `下一页` 翻页。
- `刷新` 重新加载当前页。
- `删除记录` 仅对管理员显示，删除后记录和图片将被永久删除。

## 8. MY EQP 注册

注册需要重点监控的设备后，可在设备级 SPEC 内异常检测的 `SDWT` → `MY EQP` 中只查看这些设备。

### 8.1 注册

1. 在 `选择设备参考信息` 中按 `Line Name` → `SDWT` → `PRC Group` → `EQP` 的顺序选择。
   - EQP 可多选；选择 `ALL` 会注册列表中的全部设备。
2. 在 `已选条件` 中确认所选内容。
3. 在 `监控期限` 中输入注册保持有效的天数（1 以上的整数）。
4. 如有需要，在 `备注` 中填写说明。（可选，90 字以内）
5. 在 `查看用户及邮件接收人` 中输入 knox_id 后按 Enter。
   - 本人的 knox_id 会自动加入。
   - 可指定多人，点击名称标签上的 X 可移除。
6. 点击 `保存 MY EQP`。所有必填项填写完整后按钮才可用。

### 8.2 查看与删除注册内容

在页面下方的 `已登记的 MY EQP 条件` 中查看所选产线的注册内容。

- 状态：`监控中` 或 `已到期`
- 本人的注册可用 `删除` 删除。删除后该注册中的设备将全部删除。
- 无法删除他人的公开注册。
- 注册内容不能修改。如需更改，请删除后重新注册。

## 9. 故障排查

| 页面提示·现象 | 处理方法 |
|---|---|
| `没有与所选筛选条件匹配的数据。` 等无数据提示 | 不一定是错误。请检查前面的筛选条件和搜索词。 |
| 加载失败 | 点击 `重试`。如持续失败，请将页面、时间和所选条件告知负责人。 |
| `参考映射错误` | 点击 `重试`，如持续出现请联系负责人。 |
| `算法最后运行时间` 显示 `无法确认` | 请联系负责人确认数据更新状态。 |
| Defect SPIDER 显示 `오늘(…)의 이상감지 목록 폴더가 없습니다.`（当天的异常检测列表文件夹不存在） | 当天数据尚未生成，请稍后再查看。 |
| `已登记其他 knox_id。请联系管理员。` | 请联系负责人变更用户登记。 |
| 没有 `SKIP`·`保存记录` 按钮或按钮不可用 | 图表仍在加载中，或该图表没有可保存的数据。 |

反馈问题时请勿包含密码等认证信息。

负责人：请查看主页顶部的 `开发 · 运维` 信息。
