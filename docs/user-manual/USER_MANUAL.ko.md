## 1. 시작하기

### 1.1 처음 접속할 때

처음 접속하면 `사용자 등록` 화면이 나타납니다.

1. 본인의 `knox_id`를 입력합니다. 이메일 주소(@ 포함)는 입력하지 않습니다.
2. `등록 후 시작하기`를 누릅니다.

한 번 등록하면 같은 PC에서 다시 접속할 때 자동으로 인식됩니다.

### 1.2 언어 변경

메인 화면 오른쪽 위에서 `한국어` / `English` / `中文` 중 하나를 누릅니다. 선택한 언어는 다음 접속에도 유지됩니다.

### 1.3 메인 화면

| 영역 | 내용 |
|---|---|
| `마지막 알고리즘 수행 시간` | 이상감지 데이터가 마지막으로 갱신된 시각 |
| 기능 카드 | 설비별 SPEC내 이상감지, 동일성 이상감지, 이력저장 게시판, MY EQP 등록, 사용자 매뉴얼 |
| 연계 기능 카드 | Defect SPIDER |
| `라인별 이상감지 대시보드` | 메인 화면 아래쪽의 Line별 이상 현황 |

카드를 누르면 해당 기능으로 이동합니다. 각 기능 화면의 `SPIDER 메인` 또는 `홈으로` 버튼을 누르면 메인으로 돌아옵니다.

## 2. 공통 조작

조회 화면의 필터는 **왼쪽(위쪽)부터 순서대로** 선택합니다. 앞 단계를 바꾸면 뒤 단계 선택은 초기화됩니다.

- **선택/해제**: 항목을 누르면 선택되고, 선택된 항목을 다시 누르면 해제됩니다.
- **`ALL`**: 현재 목록에 보이는 항목 전체를 한 번에 조회합니다.
- **검색**: 필터 카드의 `검색…` 칸에 입력합니다.
  - 검색 칸 왼쪽 버튼으로 `포함`(입력한 글자가 있는 항목만) 또는 `제외`(입력한 글자가 없는 항목만)를 고릅니다.
  - 대소문자는 구분하지 않습니다.
  - 검색 중에 `ALL`을 선택하면 **검색 결과에 보이는 항목만** 조회합니다.
- **필터 영역 크기**: 필터 영역 아래쪽 손잡이를 드래그해 높이를 조절합니다. 더블클릭하면 원래 크기로 돌아갑니다.
- **`다시 시도`**: 불러오기에 실패했을 때 같은 조건으로 다시 불러옵니다.
- 화면 오른쪽 아래 화살표 버튼을 누르면 맨 위로 이동합니다.

## 3. 라인별 이상감지 대시보드

메인 화면 아래쪽(상단 `대시보드` 메뉴)에서 Line별 이상 현황을 확인합니다.

1. `라인 선택`에서 볼 Line을 체크합니다. 선택하지 않으면 `전체 라인`을 조회합니다.
2. `조회`를 누릅니다.
3. 결과를 확인합니다.

| 영역 | 보는 방법 |
|---|---|
| KPI 카드 | 모니터링 센서 총합, 전체 이상 건수, Grade별 건수, `전일 대비` 증감(▲ 증가 / ▼ 감소) |
| `라인별 이상 현황` | Line별 이상 건수 막대. **막대를 누르면 해당 Line만** 조회합니다. |
| `라인별 일간 이상 추이` | 기간 버튼(10/30/90/180일)으로 범위를 바꿉니다. 범례를 누르면 해당 Line을 숨기거나 다시 표시합니다. |
| `라인 상세` | 열 제목을 눌러 정렬합니다. `상세`를 누르면 설비별 SPEC내 이상감지 화면으로 이동합니다. |

`초기화`를 누르면 전체 라인, 10일 추이와 숨긴 Line 표시 상태로 되돌아갑니다.

## 4. 설비별 SPEC내 이상감지

설비별 이상감지 차트를 확인하고, 필요하면 SKIP 처리합니다.

### 4.1 조회

1. `Line Name`을 선택합니다.
2. `SDWT`를 선택합니다.
   - `MY EQP`: 내가 등록한 MY EQP 설비만 봅니다. 등록한 설비가 있을 때만 표시됩니다.
   - `SKIP LIST`: SKIP 처리된 차트만 봅니다.
3. `센서 등급`을 선택합니다. 여러 개를 선택할 수 있습니다.
   - 등급을 선택하면 나머지 필터(`PRC_Group`, `eqp_ch`, `sensor`, `ch_step`)가 `ALL`, 상태가 `CRITICAL`로 자동 선택되고 차트가 바로 표시됩니다.
4. 범위를 좁히려면 `PRC_Group` → `eqp_ch` → `sensor` → `ch_step` 순서로 선택합니다.

### 4.2 차트 보기

| 버튼 | 기능 |
|---|---|
| `CRITICAL` / `WARNING` | 해당 상태의 이상감지만 표시합니다. 다시 누르면 전체를 표시합니다. |
| 페이지 번호 | 한 페이지에 차트 20개씩 표시합니다. |
| `ch_step 모아보기` / `전체 ch_step 보기` | 같은 EQP의 차트를 묶어 보거나 개별로 펼쳐 봅니다. (기본: 모아보기) |
| `3일 동일성 차트 표시` | 모아보기 상태에서 최근 3일(72시간) 동일성 차트를 오른쪽에 함께 표시합니다. (기본: 켜짐) |
| `동일성 차트` | 같은 데이터의 다른 설비와 비교하는 창을 엽니다. 현재 EQP는 빨간색입니다. `기준선 긋기`를 켜고 두 번 클릭하면 기준 구간을 표시합니다. |
| `변경점 이력` | 설비 작업 이력을 표로 봅니다. `LINK`가 있으면 관련 화면을 엽니다. |
| `이력 저장` | 차트를 이미지와 함께 [이력저장 게시판](#7-이력저장-게시판)에 저장합니다. |

차트 조작: **드래그로 확대**, **더블클릭으로 원래 범위**. 빨간 점은 이상감지 데이터, 회색 점은 이전 데이터, 초록 점선은 변경점입니다.

### 4.3 SKIP

| 버튼 | 기능 |
|---|---|
| `SKIP` | 현재 차트를 이상감지에서 제외합니다. 사유(한 줄, 선택)를 입력하고 `확인`을 누릅니다. |
| `EQP ALL SKIP` | 해당 EQP·sensor의 모든 ch_step을 한 번에 제외합니다. |
| `SKIP 해제` | 제외한 차트를 다시 이상감지 대상으로 되돌립니다. |

SKIP한 차트는 `SDWT` → `SKIP LIST`에서 확인하고 해제할 수 있습니다. 작업 전 대상 EQP와 sensor를 다시 확인하세요.

## 5. 동일성 이상감지

같은 조건의 설비 간 신호 분포를 비교한 그래프를 봅니다.

1. `Line Name`을 선택합니다. (첫 번째 Line 자동 선택)
2. `SDWT`를 선택합니다. (첫 번째 SDWT 자동 선택)
3. `STEP`을 선택합니다. `ALL`은 해당 SDWT의 모든 STEP입니다.
4. `Sensor`를 선택합니다.
5. `ch_step`을 선택하면 그래프가 표시됩니다. Sensor가 `ALL`이면 ch_step도 `ALL`만 선택할 수 있습니다.

결과는 `동일성 기반 이상감지 그래프`에 step_seq별로 묶여 표시됩니다.

- 한 페이지에 18개씩 표시되며, 아래 페이지 번호로 이동합니다.
- 각 그래프의 `이력 저장`으로 [이력저장 게시판](#7-이력저장-게시판)에 저장할 수 있습니다.

## 6. Defect SPIDER 사용법

Defect 신호 기준의 이상감지 결과를 차트로 확인합니다. 데이터는 **오늘 날짜의 최신 이상감지 목록**을 기준으로 표시됩니다.

### 6.1 조회

1. `스탭 구분`을 선택합니다.
   - `관리스탭`(기본): 관리스탭 기준 이상감지 결과
   - `DEPO후 스탭`: DEPO 이후 스탭 기준 이상감지 결과
2. `Line Name`을 선택합니다. (첫 번째 Line 자동 선택)
3. `SDWT`를 선택합니다. (첫 번째 SDWT 자동 선택)
4. `PRC Group`을 선택합니다. 기본값 `ALL`은 모든 PRC Group의 차트를 표시합니다.

`스탭 구분`을 바꾸면 PRC Group 선택은 `ALL`로 돌아가고, 선택한 스탭의 데이터로 차트를 다시 그립니다.

### 6.2 차트 보기

차트는 PRC Group별로 묶이고, eqp_ch마다 하나씩 표시됩니다. 차트 제목은 `eqp_ch / main_seq / met_seq` 정보입니다.

| 표시 | 의미 |
|---|---|
| 작고 옅은 점 | ALL 데이터 (STEP별 색상) |
| 크고 진한 점 | 이상감지 RAW 데이터 (빨강: NG, 청록: 그 외) |
| 초록 점선 | 변경점 (PM이력) |
| 오른쪽 범례 | STEP별 색상과 건수, eqp_ch 목록. **eqp_ch를 누르면** 해당 설비 점을 숨기거나 다시 표시합니다. |

차트 조작:

- **드래그**: 선택 영역 확대
- **반대 방향 드래그**: 처음 범위로 복귀
- **더블클릭** 또는 `범위 초기화`: 전체 범위 보기

### 6.3 상세 확인

- `이상감지 Wafer List 보기`: 이상감지 Wafer 목록을 표로 엽니다. 셀을 드래그하거나 열 제목을 눌러 선택한 뒤 `복사`(또는 Ctrl+C)를 누르면 엑셀에 붙여넣을 수 있습니다.
- `PM이력 보기`: 해당 설비의 PM 이력을 표로 엽니다.

## 7. 이력저장 게시판

각 화면의 `이력 저장`으로 저장한 차트를 모아 봅니다. 저장 직후 나오는 창에서 `이력저장 게시판으로 이동`을 눌러도 됩니다.

1. 필요하면 조건을 입력합니다: `Line Name`, `SDWT`, `등록자`, `저장 시작일`, `저장 종료일`.
   - Line Name, SDWT, 등록자는 **정확히 같은 값**으로 입력해야 검색됩니다.
2. `조회`(또는 Enter)를 누릅니다. `초기화`는 조건을 모두 지웁니다.
3. 목록에서 `이력 상세`를 누르면 저장 당시 차트 이미지와 정보를 볼 수 있습니다.

- 최신 저장 순으로 한 페이지에 20개씩 표시됩니다. `이전` / `다음`으로 이동합니다.
- `새로고침`은 현재 페이지를 다시 불러옵니다.
- `이력 삭제`는 관리자 권한 사용자에게만 보이며, 삭제하면 이미지와 함께 영구 삭제됩니다.

## 8. MY EQP 등록

집중 모니터링할 설비를 등록하면 설비별 SPEC내 이상감지의 `SDWT` → `MY EQP`에서 해당 설비만 모아 볼 수 있습니다.

### 8.1 등록

1. `설비 기준정보 선택`에서 `Line Name` → `SDWT` → `PRC Group` → `EQP` 순서로 선택합니다.
   - EQP는 여러 개 선택할 수 있고, `ALL`을 선택하면 목록의 모든 설비가 등록됩니다.
2. `선택 조건`에서 선택 내용을 확인합니다.
3. `모니터링 기간`에 등록을 유지할 일수(1 이상 정수)를 입력합니다.
4. 필요하면 `비고 입력`에 메모를 남깁니다. (선택, 90자 이내)
5. `열람 및 메일수신인 지정`에 knox_id를 입력하고 Enter를 누릅니다.
   - 내 knox_id는 자동으로 들어가 있습니다.
   - 여러 명을 지정할 수 있고, 이름표의 X를 누르면 뺄 수 있습니다.
6. `My EQP 저장`을 누릅니다. 필수 항목이 모두 입력되어야 버튼이 활성화됩니다.

### 8.2 등록 내역 확인과 삭제

화면 아래 `등록된 My EQP 조건`에서 선택한 Line의 등록 내역을 확인합니다.

- 상태: `모니터링 중` 또는 `기간 만료`
- 내 등록 건은 `삭제`로 지울 수 있습니다. 삭제하면 그 등록 건의 설비가 모두 삭제됩니다.
- 다른 사람의 공개 등록 건은 삭제할 수 없습니다.
- 등록 내용은 수정할 수 없습니다. 바꾸려면 삭제 후 다시 등록합니다.

## 9. 문제 해결

| 화면 메시지·증상 | 조치 |
|---|---|
| `선택한 필터와 일치하는 데이터가 없습니다.` 등 데이터 없음 안내 | 오류가 아닐 수 있습니다. 앞 단계 필터와 검색어를 확인합니다. |
| 불러오기 실패 | `다시 시도`를 누릅니다. 계속되면 화면, 시각, 선택 조건을 담당자에게 전달합니다. |
| `기준정보 매핑 오류` | `다시 시도`를 누르고, 계속되면 담당자에게 문의합니다. |
| `마지막 알고리즘 수행 시간`이 `확인 불가` | 데이터 갱신 상태 확인을 담당자에게 요청합니다. |
| Defect SPIDER에서 `오늘(…)의 이상감지 목록 폴더가 없습니다.` | 오늘 데이터가 아직 생성되지 않았습니다. 잠시 후 다시 확인합니다. |
| `다른 knox_id가 이미 등록되어 있습니다.` | 담당자에게 사용자 등록 변경을 요청합니다. |
| `SKIP`·`이력 저장` 버튼이 없거나 비활성 | 차트가 아직 불러오는 중이거나, 저장할 데이터가 없는 차트입니다. |

문의할 때 비밀번호 등 개인 인증 정보는 보내지 마세요.

담당자: 메인 화면 상단 `개발 · 운영` 표시를 확인하세요.
